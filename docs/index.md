  title: Built on the newest standards
  details: Popover API, Invoker Commands, CSS Anchor Positioning, scroll-driven animations, scroll-state queries, @starting-style, interest invokers and more — used today, with graceful fallbacks.
- icon: 🚀
  title: CSS-first, minimal JavaScript
  details: Dialogs, popovers, tooltips or accordions work without a single line of JavaScript. Carousel and drawer are driven by native scroll-snap with just a tiny JS layer on top.
- icon: 📦️
  title: Modular and customizable
  details: Each component is written in plain CSS, so you can copy and paste it, or import it from npm and customize it with CSS properties.
- icon: ✨️
  title: Accessible web standards
  details: Components build on native elements — &lt;dialog&gt;, [popover], &lt;details&gt;, radio and checkbox inputs — so focus management, keyboard support and semantics come from the platform.
- icon: 🧩
  title: Framework agnostic
  details: Everything is written in plain CSS and JS, so you can use it with any framework you want. Pre-built components are available for Web Components, Stimulus, Vue and React.
- icon: 🎨
  title: Extends TailwindCSS
  details: Adds new handy utilities, variants and CSS properties on top of TailwindCSS v4. You don't even need to use TailwindCSS, but it's recommended for the full experience.
